# sysml-web

A web workbench for **SysML v2** where the model's textual notation in git is
the single source of truth. It offers text and visual editing, the standard
views, and tools for systems, test, quality and development engineers. It is
built to conform to the OMG standard so models can be exchanged with other
tools.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md).
